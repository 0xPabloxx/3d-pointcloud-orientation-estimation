# 3D点云正面方向预测 - 实验总结报告

---

## 1. 问题定义

### 1.1 任务目标

给定一个3D点云，预测物体可能的正面方向。关键挑战：**物体可能有多个等效正面方向**。

| 物体类型 | 正面数K | 示例 |
|---------|--------|------|
| 1_front | 1 | 椅子(只有前后之分) |
| 2_fronts | 2 | 沙发(前后两面对称) |
| 4_fronts | 4 | glassbox(四面等效) |
| symmetric | 0 | 圆柱体(任意方向) |
| no_front | 0 | 无明确正面 |

### 1.2 建模方法

使用 **Mixture of von Mises (MvM)** 分布建模方向的不确定性：

$$p(\theta | x) = \sum_{i=1}^{K} w_i \cdot \text{VM}(\theta | \mu_i, \kappa_i)$$

其中：
- $\mu_i$: 第i个峰的方向 $(cos\theta, sin\theta)$
- $\kappa_i$: 第i个峰的集中度 (越大越尖锐, 0=均匀分布)
- $w_i$: 第i个峰的权重 ($\sum w_i = 1$)

**von Mises PDF**:
$$\text{VM}(\theta | \mu, \kappa) = \frac{\exp(\kappa \cos(\theta - \mu))}{2\pi I_0(\kappa)}$$

## 3. 实验记录

### 实验1: Zeros初始化 (失败)

**配置**:
- Model: PointNet++ backbone + MvM预测头
- Loss: KL散度 + 匈牙利匹配
- μ head初始化: zeros (所有峰从μ=0开始)

**结果**:
- Val Loss: **0.74** (不下降)
- 预测: μ=[0,0,0,0], w=[0.99, 0.003, 0.003, 0.003]
- **模型退化为单峰分布**

**失败原因** (核心问题):

```
4个峰初始化为相同值 (μ=0)
    ↓
Loss对每个峰的梯度相同: ∂L/∂μ₁ = ∂L/∂μ₂ = ∂L/∂μ₃ = ∂L/∂μ₄
    ↓
4个峰永远一起移动，无法分开 (对称性陷阱)
    ↓
模型发现"作弊"策略: 让1个峰的weight→1, 其他→0
    ↓
Loss = 0.74 (局部最优)
```

---

### 实验2: 预设角度初始化 + 数据增强 (成功)

**改进**:
- μ初始化: 预设[0°, 90°, 180°, 270°]，打破对称性
- 数据增强: 12个旋转角度 (30°间隔)

**初始化代码**:
```python
initial_angles = [0, π/2, π, 3π/2]
for i, angle in enumerate(initial_angles):
    self.head_mu.bias[2*i]   = cos(angle)
    self.head_mu.bias[2*i+1] = sin(angle)
```

**结果**:
- Val Loss: **0.0017** (↓435倍)
- Test Loss: **0.0131**
- 预测: 4个峰清晰分布在正确位置

**对比**:
| 指标 | Zeros初始化 | 预设初始化 | 改进 |
|------|------------|-----------|------|
| Val Loss | 0.74 | 0.0017 | 435× |
| μ分散 | 全部=0 | [0°,90°,180°,270°] | ✓ |
| 收敛 | 不收敛 | 20 epoch | ✓ |

### 实验3: 可学习Weight vs 固定Weight

**发现的问题**: 即使初始化正确，如果weight可学习，仍会发生mode collapse。

**数学分析**:

使用的Loss:
$$\mathcal{L} = \sum_{i=1}^{K} w_i^{\text{pred}} \cdot \text{KL}(P_i^{\text{pred}} \| P_{\sigma(i)}^{\text{GT}})$$

问题:
- 如果模型让 $w_1^{\text{pred}}=0.99$, 其他$w\approx 0$
- 只有Peak 1的KL会被计算
- 其他Peak即使位置错误，也不影响Loss

**数值例子**:
```
GT:   4峰等权重 [0°, 90°, 180°, 270°]
Pred: w=[0.99, 0.003, 0.003, 0.003], μ=[0°, 45°, 135°, 225°] (3个位置错误!)

Loss = 0.99×KL(0°||0°) + 0.003×KL(45°||90°)×3
     = 0.99×0 + 0.003×14.6×3
     = 0.13   <- 看起来很小，但预测完全错误!
```

**解决方案**: 固定weight=0.25

$$\mathcal{L} = \frac{1}{4} \sum_{i=1}^{4} \text{KL}(P_i^{\text{pred}} \| P_{\sigma(i)}^{\text{GT}})$$

**结果对比**:
| Weight策略 | Val Loss | 预测质量 |
|-----------|----------|---------|
| 可学习 | 0.05 (假低) | 只有1个峰正确 |
| 固定0.25 | 0.0017 (真低) | 4个峰都正确 |

### 实验4: Fixed 4-Peak训练 (最新)

**数据**: 798 train × 10增强 = 7980, 228 val
**模型**: PointNet++ (1.6M参数)

#### Exp-4-1: Pure KL Loss

$$\mathcal{L} = \text{KL}(p_{\text{GT}} \| p_{\text{pred}})$$

**结果**:
- Val KL: 0.32 (从epoch 2开始不下降)
- 预测κ ≈ 0 (模型输出均匀分布)

**原因**: κ→0是KL Loss的"安全"选项
- 输出均匀分布时，无论GT是什么，KL都有一个保底值
- 梯度引导模型降低κ而不是调整μ

---

#### Exp-4-2: KL + κ监督

$$\mathcal{L} = \text{KL} + \lambda_\kappa \cdot \text{SmoothL1}(\kappa_{\text{pred}}/50, \kappa_{\text{GT}}/50)$$

**结果**:
- Val KL: **0.45** (反而更差!)
- κ被强制接近GT值，但μ方向仍错误
- 尖峰在错误位置 → KL更大

---

#### Exp-4-3: KL + κ + μ监督

$$\mathcal{L} = \text{KL} + \lambda_\kappa L_\kappa + \lambda_\mu L_\mu$$

其中:
$$L_\mu = \text{mean}(1 - \cos(\theta_{\text{pred}} - \theta_{\text{GT}})) \quad [\text{只对有效峰}]$$

**结果**:
- 4_fronts KL: 1.52 → 1.24 (改善但仍不如Pure KL)
- **KL Loss和参数监督目标冲突**

---

#### Exp-4-4: 只用κ + μ监督 (移除KL)

$$\mathcal{L} = \lambda_\kappa L_\kappa + \lambda_\mu L_\mu$$

**结果** (最佳):
- Val κ_loss: **0.042**
- Val μ_loss: **0.082**
- Best val loss: **0.352**
- 训练稳定，κ和μ都能正常学习

---

### 实验结果汇总

| 实验 | Loss配置 | Val Loss | 问题 |
|-----|----------|----------|-----|
| Exp-1 | Pure KL | 0.32 | κ坍塌到0 |
| Exp-2 | KL+κ监督 | 0.45 | μ错误,KL更大 |
| Exp-3 | KL+κ+μ监督 | 0.40 | Loss冲突 |
| **Exp-4** | **只用κ+μ监督** | **0.35** | **✓ 最佳** |

## 4. 核心问题总结

### 问题1: 对称初始化陷阱 ✓已解决

**症状**: 所有峰预测相同方向
**原因**: zeros初始化导致梯度相同
**解决**: 预设角度初始化 [0°, 90°, 180°, 270°]

### 问题2: Weight Exploitation ✓已解决

**症状**: 只有1个峰有高weight，其他≈0
**原因**: 可学习weight允许模型"作弊"
**解决**: 固定weight=0.25

### 问题3: κ坍塌 ⚠️部分解决

**症状**: Pure KL导致κ→0 (输出均匀分布)
**原因**: 均匀分布是KL Loss的"安全"选项
**当前方案**: 用κ+μ监督替代KL Loss

### 问题4: KL与参数监督冲突 ❓待研究

**症状**: 添加κ/μ监督反而让KL更差
**原因**: KL希望κ→0(安全), 监督希望κ→50(准确)
**待解决**:
- 如何让KL Loss正常工作?
- 是否有更好的Loss设计?

## 5. 待解决的核心问题

### 5.1 Loss设计问题

**当前困境**:
- Pure KL: κ坍塌
- KL + 监督: 目标冲突
- 只用监督: 可行但放弃了KL的分布匹配能力

**可能方向**:
1. **两阶段训练**: 先用μ+κ监督预训练，再用KL微调
2. **KL方向**: 改用KL(GT||Pred)而非KL(Pred||GT)
3. **温度退火**: 训练初期κ目标值小，逐渐增大
4. **Curriculum Learning**: 先学简单样本(1峰)，再学复杂(4峰)

### 5.2 评估指标问题

**当前用的KL散度**难以反映实际预测质量:
- KL=0.3可能是"正确但κ小"或"错误但κ小"
- 需要分离评估: 角度误差、κ误差、分类准确率

**建议指标**:
- 角度误差: $\min_j |\theta_{\text{pred}}^i - \theta_{\text{GT}}^j|$ (考虑匹配)
- κ相对误差: $|\kappa_{\text{pred}} - \kappa_{\text{GT}}| / \kappa_{\text{GT}}$
- 峰数分类准确率

### 5.3 混合数据的挑战

**问题**: 训练集包含K=1,2,4,0的混合数据
- K=0(symmetric/no_front)的GT是均匀分布(κ=0)
- 这会"教"模型输出κ=0是安全的

**可能方案**:
1. 分类别训练，每个K单独模型
2. 先预测K，再预测参数
3. 调整K=0样本的权重

## 6. 关键公式汇总

### von Mises分布
$$\text{VM}(\theta|\mu,\kappa) = \frac{\exp(\kappa\cos(\theta-\mu))}{2\pi I_0(\kappa)}$$

### 两个vM分布的KL散度
$$\text{KL}(\text{VM}_p \| \text{VM}_q) = \log\frac{I_0(\kappa_q)}{I_0(\kappa_p)} + A(\kappa_p)[\kappa_p - \kappa_q\cos(\mu_p-\mu_q)]$$

其中 $A(\kappa) = I_1(\kappa)/I_0(\kappa)$

### 角度Loss (cosine距离)
$$L_\mu = 1 - \cos(\theta_{\text{pred}} - \theta_{\text{GT}}) \in [0, 2]$$

### 匈牙利匹配Cost
$$\text{Cost}_{ij} = (1-\cos(\mu_i^{\text{pred}}-\mu_j^{\text{GT}})) + 0.1|\kappa_i^{\text{pred}}-\kappa_j^{\text{GT}}|/50$$
