## PointNet++ Backbone 详细结构

```
Input: [B, 2048, 3] (xyz coordinates)
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│  Set Abstraction Layer 1 (SA1)                              │
│  ├─ FPS: 2048 → 512 points (random start in training)       │
│  ├─ Ball Query: r=0.2, nsample=32                           │
│  ├─ PointNet MLP: [3] → [64, 64, 128]                       │
│  └─ Output: [B, 512, 128]                                   │
└─────────────────────────────────────────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│  Set Abstraction Layer 2 (SA2)                              │
│  ├─ FPS: 512 → 128 points                                   │
│  ├─ Ball Query: r=0.4, nsample=64                           │
│  ├─ PointNet MLP: [128+3] → [128, 128, 256]                 │
│  └─ Output: [B, 128, 256]                                   │
└─────────────────────────────────────────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│  Set Abstraction Layer 3 (SA3) - Global                     │
│  ├─ Group All: 128 → 1 point (global pooling)               │
│  ├─ PointNet MLP: [256+3] → [256, 512, 1024]                │
│  └─ Output: [B, 1, 1024] → [B, 1024] (flatten)              │
└─────────────────────────────────────────────────────────────┘
           │
           ▼
     Global Feature
       [B, 1024]
```

## Expert Head 结构

```
Global Feature [B, 1024]
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│  Expert Head (e.g., 2-Front)                                │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Linear(1024, 256) + ReLU                            │    │
│  └─────────────────────────────────────────────────────┘    │
│           │                                                 │
│           ▼                                                 │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Linear(256, 256) + ReLU                             │    │
│  └─────────────────────────────────────────────────────┘    │
│           │                                                 │
│           ▼                                                 │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Linear(256, K×3)   K=2 for 2-Front                  │    │
│  └─────────────────────────────────────────────────────┘    │
│           │                                                 │
│           ▼                                                 │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Reshape to [B, K, 3]                                │    │
│  │ Split: cos, sin, raw_κ                              │    │
│  │                                                     │    │
│  │ μ = atan2(sin, cos)     ← angle in [-π, π]          │    │
│  │ κ = softplus(raw_κ)     ← concentration > 0         │    │

│  └─────────────────────────────────────────────────────┘    │
│           │                                                 │
│           ▼                                                 │
│  Output: {mu: [B,K], kappa: [B,K]}                          │
└─────────────────────────────────────────────────────────────┘
```

## 训练 vs 推理路由

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              TRAINING                                        │
│                         (GT Hard Routing)                                    │
│                                                                              │
│   GT Label                                                                   │
│      │                                                                       │
│      ▼                                                                       │
│   ┌─────┐    Label=0     ┌──────────────┐                                   │
│   │  0  │ ───────────────▶ Expert 1-Front ───▶ NLL Loss                     │
│   ├─────┤    Label=1     ├──────────────┤                                   │
│   │  1  │ ───────────────▶ Expert 2-Front ───▶ Hungarian + NLL               │
│   ├─────┤    Label=2     ├──────────────┤                                   │
│   │  2  │ ───────────────▶ Expert 4-Front ───▶ Hungarian + NLL               │
│   ├─────┤    Label=3,4   ├──────────────┤                                   │
│   │ 3,4 │ ───────────────▶    SKIP       (no direction loss)                │
│   └─────┘                └──────────────┘                                   │
│                                                                              │
│   Note: Classifier weights NOT used for routing during training              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                              INFERENCE                                       │
│                        (Soft Routing / Fusion)                               │
│                                                                              │
│   Classifier                                                                 │
│   Weights        Expert Outputs                  Final PDF                   │
│      │                 │                             │                       │
│      ▼                 ▼                             ▼                       │
│   ┌─────┐         ┌─────────┐                                               │
│   │ w₀  │ ──×──── │ P₁(θ)   │ ──┐                                           │
│   ├─────┤         ├─────────┤   │                                           │
│   │ w₁  │ ──×──── │ P₂(θ)   │ ──┼──▶  P(θ) = Σᵢ wᵢ·Pᵢ(θ)                    │
│   ├─────┤         ├─────────┤   │                                           │
│   │ w₂  │ ──×──── │ P₄(θ)   │ ──┤                                           │
│   ├─────┤         ├─────────┤   │                                           │
│   │w₃+w₄│ ──×──── │Uniform  │ ──┘                                           │
│   └─────┘         └─────────┘                                               │
│                                                                              │
│   Note: All experts contribute, weighted by classifier confidence            │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 参数量统计

| 组件 | 参数量 | 可训练 (freeze=True) |
|------|--------|---------------------|
| **Classifier (Gate)** | | |

| └─ FC layers | ~0.61M | No |
| **Shared Backbone** | | |
| └─ SA1 (3→128) | ~0.05M | Yes |
| └─ SA2 (131→256) | ~0.17M | Yes |
| └─ SA3 (259→1024) | ~1.33M | Yes |
| **Expert Heads** | | |
| └─ Head 1-Front (1024→256→256→3) | ~0.33M | Yes |
| └─ Head 2-Front (1024→256→256→6) | ~0.33M | Yes |
| └─ Head 4-Front (1024→256→256→12) | ~0.33M | Yes |
| **Total** | **~3.95M** | **~1.80M** |
