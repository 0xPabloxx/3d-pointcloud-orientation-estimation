# 对称性分类网络架构详解

## 网络输出说明

**输出**: `logits` (B, 5) - 5个类别的原始分数

**转换为概率**:
```python
probs = F.softmax(logits, dim=1)  # (B, 5)
```

**类别索引到K值的映射**:
```
idx=0 → K=-1 (没有正面)
idx=1 → K=0  (完全对称)
idx=2 → K=1  (1个正面)
idx=3 → K=2  (2个正面)
idx=4 → K=4  (4个正面)
```

## 🔍 PointNet++ Set Abstraction Layer 详解

每个SA层包含3个步骤：

### 1. **FPS (Farthest Point Sampling)**
```
作用: 从N个点中采样npoint个点
例如: 10000 → 512 points
方法: 贪心算法，每次选择距离已选点最远的点
```

### 2. **Ball Query**
```
作用: 为每个采样点找到半径内的邻居点
参数: radius (半径), nsample (最多采样数)
例如: 每个中心点找32个邻居
```

### 3. **PointNet (MLP + MaxPooling)**
```
作用: 对每个局部区域提取特征
流程:
  输入: 局部点云 (B, npoint, nsample, 3+D)
  ↓ MLP [64, 64, 128] - 逐点卷积
  ↓ BatchNorm + ReLU
  ↓ MaxPooling (nsample维度)
  输出: (B, npoint, 128)
```

## 📐 完整前向传播示例

```python
# 输入
points = torch.randn(4, 10000, 3)  # Batch=4
upright_vec = torch.tensor([[0,1,0]] * 4)  # (4, 3)

# Forward (GlobalConcat)
model = SymmetryClassifier_GlobalConcat()
logits = model(points, upright_vec)  # (4, 5)

# 输出示例
print(logits)
# tensor([[ 0.12, -1.34,  2.56, -0.89,  0.34],
#         [-0.45,  0.78,  3.21, -1.12,  0.11],
#         [ 1.23, -2.01,  0.89,  1.45, -0.34],
#         [ 0.56, -0.34,  4.12, -0.78,  0.23]])

# 转为概率
probs = F.softmax(logits, dim=1)
print(probs)
# tensor([[0.10, 0.02, 0.72, 0.04, 0.12],  # 预测class 2 (K=1)
#         [0.05, 0.16, 0.68, 0.03, 0.08],  # 预测class 2 (K=1)
#         [0.28, 0.01, 0.20, 0.34, 0.06],  # 预测class 3 (K=2)
#         [0.05, 0.02, 0.87, 0.01, 0.04]]) # 预测class 2 (K=1)

# 预测类别
preds = torch.argmax(probs, dim=1)
print(preds)  # tensor([2, 2, 3, 2])

# 转为K值
K_mapping = {0: -1, 1: 0, 2: 1, 3: 2, 4: 4}
K_values = [K_mapping[p.item()] for p in preds]
print(K_values)  # [1, 1, 2, 1]
```

## 🎯 关键设计思想

### 1. **为什么用PointNet++？**
- ✅ 局部+全局特征提取（SA层的层级结构）
- ✅ 对点云旋转不变性（通过局部坐标系）
- ✅ 成熟稳定，易于训练

### 2. **为什么要3种Upright输入方式？**
- **GlobalConcat**: 认为upright信息是全局的，在最后特征层融合
- **PointConcat**: 认为upright信息应该参与局部特征提取
- **NoUpright**: Baseline，测试是否真的需要upright信息

### 3. **为什么用4层MLP分类器？**
- 逐步降维：1027 → 512 → 256 → 128 → 5
- Dropout(0.5) 防止过拟合
- BatchNorm 加速收敛

### 4. **为什么用CrossEntropyLoss？**
- 自动内部softmax + 负对数似然
- 适合多分类任务
- 支持类别权重（处理不平衡数据）

## 💡 训练时的数据流

```
数据加载:
  ├─ 读取PLY点云 → 归一化 → 随机旋转 → 采样10000点
  └─ 读取标注K值 → 转为class索引 (0-4)

输入模型:
  ├─ points: (B, 10000, 3)
  └─ upright_vec: (B, 3) = [0,1,0]

前向传播:
  └─ logits: (B, 5)

计算损失:
  ├─ loss = CrossEntropyLoss(logits, labels)
  └─ 支持类别权重 (处理不平衡)

反向传播:
  └─ optimizer.step()

预测:
  ├─ probs = softmax(logits)
  ├─ pred_class = argmax(probs)
  └─ pred_K = K_mapping[pred_class]
```

## 📊 输出解释示例

假设某个airplane样本（K=1，单正面）:

```python
# 网络输出（未归一化）
logits = tensor([0.1, -2.3, 5.7, -1.2, 0.8])
         #       K=-1  K=0  K=1  K=2  K=4

# 转为概率（softmax）
probs = tensor([0.02, 0.00, 0.96, 0.01, 0.01])
        #       ↑没有正面
        #            ↑完全对称
        #                 ↑1个正面 (最高！)
        #                      ↑2个正面
        #                           ↑4个正面

# 预测结果
pred_class = 2  (argmax)
pred_K = 1      (K_mapping[2] = 1)
✅ 正确！这是一个单正面物体
```

**总结**:
- 输出是5个分数（logits），对应5个K值类别
- 通过softmax转为概率分布
- 通过argmax得到预测类别
- 训练时用CrossEntropyLoss（自动处理softmax）
